腕時計のボタンをタップするだけで、自宅の SESAME（セサミ） 5 を解錠・施錠する方法を紹介します。使うのは、Amazfit（アマズフィット） T-Rex 2 と、Amazfit の時計で動くミニアプリ「HTTP」です。

「HTTP」アプリは、時計から HTTP リクエストを送れるミニアプリです。送り先と内容を一度設定しておけば、時計のボタンを押すだけで、そのリクエストを送ってくれます。

「HTTP」アプリが動く Amazfit の時計なら、T-Rex 2 以外でも同じ方法でできます。

HTTP リクエストを受け取る側には、本来はサーバーが必要です。この記事では、Google Apps Script(GAS)を使うことで、サーバーを用意せずに実現します。

**注意**: この記事の内容は、玄関の鍵を操作するものです。APIキーやシークレットキーなどの秘密情報は、記事や GitHub に絶対に載せないでください。

## 仕組み

- **時計の「HTTP」アプリ**: ボタンを押すと、リクエストを送る
- **GAS**: リクエストを受け取る中継役。SESAME の API に命令を送る
- **SESAME Web API**: クラウド経由で SESAME 5 を動かす

## この記事でやること

1. SESAME の準備をする
2. GAS にコードを入れる
3. GAS を Web アプリとして公開する
4. 時計に「HTTP」アプリを入れる
5. 解錠・施錠のボタンを作る
6. 時計で試す

## 準備するもの

- SESAME 5 と Wi-Fiモジュール2(SESAME 5 がインターネットにつながっている状態にしておく必要があります)
- SESAME アプリ(SESAME 5 を登録済みのもの)
- Amazfit T-Rex 2 と、Zepp アプリを入れたスマホ
- Google アカウント
- パソコン(なくても可能ですが、GAS の画面はパソコンのほうが操作しやすいです)

※ミニアプリ「HTTP」は、第三者(作者: galulex 氏)が開発した Amazfit 用のアプリです。アプリ内課金があります。利用は自己責任でお願いします。

## 手順1 SESAME の準備をする

GAS から SESAME を動かすために、次の3つの情報が必要です。

- **APIキー**: SESAME の Web API を使うための鍵
- **UUID**: 操作する SESAME を指定する ID
- **シークレットキー**: 命令に署名するための鍵

この手順は、CANDY HOUSE が公開している情報と、有志の方が公開している資料をもとにしています。画面の表示やメニュー名は、変更されている場合があります。

### A. APIキーを取得する

APIキーは、CANDY HOUSE の法人向けサービス「SESAME Biz」の、開発者向けのページで取得します。

1. スマホやパソコンのブラウザで、「biz.candyhouse.co」を開きます。
2. メールアドレスを入力して、ログインします。
3. ログインしたら、画面の左上にあるメニューを開きます。
4. メニューの中から、「開発者向け」を選びます。
5. 表示されたページで、APIキーをコピーします。
6. コピーしたAPIキーを、メモ帳などに控えます。

### B. シークレットキーと UUID を取得する

この2つは、SESAME アプリの「鍵のシェア」で表示される QR コードから取り出します。

1. スマホの SESAME アプリを開き、SESAME 5 を選びます。
2. 「鍵をシェア」を選びます。メニュー名は、アプリのバージョンによって多少異なります。
3. 鍵の種類は、「マネージャー」(または「オーナー」)を選びます。「ゲスト」の鍵では、取り出せません。
4. QR コードが表示されたら、スクリーンショットを撮ります。
5. ブラウザで、QR コード読み取りツール(`sesame-qr-reader.vercel.app`)を開きます。
6. 撮ったスクリーンショットを、ツールにアップロードします。
7. 読み取り結果に、「Secret Key」と「UUID」が表示されます。2つをコピーして、メモ帳などに控えます。
8. 控え終わったら、QR コードのスクリーンショットを削除します。「最近削除した項目」(ゴミ箱)からも、削除してください。

QR コードは、鍵そのものです。他人に見せたり、ネットに載せたりしないでください。この記事に QR コードの画像を載せていないのも、そのためです。

UUID は、SESAME アプリのデバイス情報の画面でも、確認できます。

### C. 3つの情報を確認する

3つとも、メモ帳などに控えたら、手順1は完了です。人に見せたり、ネットに載せたりしないでください。

## 手順2 GAS にコードを入れる

1. 「新しいプロジェクト」をクリックします。
2. 左上の「無題のプロジェクト」をクリックして、「SESAME」など、わかりやすい名前に変えます。
3. エディタに最初から入っているコードを、すべて削除します。
4. 次のコードを貼り付けます。

## 手順3 GAS を Web アプリとして公開する

1. 画面右上の「デプロイ」から「新しいデプロイ」を選びます。
2. 種類の歯車アイコンから「ウェブアプリ」を選びます。
3. 「次のユーザーとして実行」は「自分」にします。
4. 「アクセスできるユーザー」は「全員」にします。時計のアプリは、Google にログインしていないためです。
5. 「デプロイ」を押し、初めての場合に出る権限の承認画面で、許可します。
6. 表示された「ウェブアプリ」の URL をコピーして、メモ帳などに控えます。手順5で使います。

※コードを書き換えたときは、「デプロイを管理」から新しいバージョンに更新しないと、公開中のものに反映されません。

## 手順4 時計に「HTTP」アプリを入れる

1. スマホで Zepp アプリを開きます。
2. T-Rex 2 のアプリストアを開きます。
3. アプリストアで「ユーティリティ」のカテゴリを開き、「HTTP」を検索します。作者が「galulex」のものです。
4. インストールします。

## 手順5 解錠・施錠のボタンを作る

「HTTP」アプリの設定は、Zepp アプリから行います。時計のボタンひとつにつき、リクエストをひとつ設定します。解錠用と施錠用の、2つを作ります。

1. Zepp アプリで、「HTTP」アプリの設定画面を開きます。
2. カスタムアクションを追加します。
3. 次の表のとおりに入力します。

**TITLE**
`UNLOCK` （施錠用を作る場合は `LOCK`）

**METHOD**
`GET`

**URL**
手順3でコピーしたURLの**一番最後**に、以下の文字を追加して入力します。
（解錠用）`?action=unlock`
（施錠用）`?action=lock`

※入力例: `https://script.google.com/macros/s/xxxx/exec?action=unlock`

**HEADERS**
空欄のまま

**BODY**
空欄のまま

アプリの説明では、1画面に1〜4個のボタンを並べられます。無料版で作れるアクションの数には、上限があります。上限を超える場合は、有料の Pro が必要です。

## 手順6 時計で試す

まず、動きを目で確認しやすい「施錠」から試します。
1. 時計で「HTTP」アプリを開き、施錠のボタンをタップします。
2. SESAME が動いたかを、目で見て確認します。SESAME アプリで、状態を見ても構いません。
3. 問題なければ、解錠も試します。

## うまく動かないとき

- Web アプリの URL が、正しくコピーできているか確認します。
- コードを書き換えた場合は、「デプロイを管理」で新しいバージョンに更新したか確認します。
- SESAME 5 が、Wi-Fiモジュール2を通じてインターネットにつながっているか確認します。
- 画面に結果が「成功」と出ても、実際に鍵が動いたとは限りません。SESAME アプリで状態を確認してください。

## セキュリティ上の注意

**Web アプリの URL は、玄関の鍵と同じです。** 他人に知られると、誰でも解錠できる可能性があります。

- URLは、推測されにくい長いランダム文字列にします。（※GASのURL自体が長いランダム文字列になっています）
- 秘密情報は、記事や GitHub に実際の値を載せません。
- 漏れたかもしれないときは、デプロイを削除して作り直します。SESAME の APIキーも、必要に応じて再発行します。
- **万が一に備え、URLは絶対にSNSやブログに公開せず、厳重に管理してください。**

## まとめ

時計のアプリから HTTP リクエストを送り、GAS で受け取ることで、サーバーなしで SESAME 5 を腕時計から操作できました。使う前に、漏えいしたときの対応手順を決めておくことをおすすめします。

これが大正解でした！画面のフチまで綺麗に覆ってくれるので、隙間から埃が入る心配もありません。端の表示が歪むこともなく、見た目もスッキリ。まさに**「これが欲しかったぴったりサイズだ！」**と大満足です。バンパーカバーなどをつけずに、時計のフチまでカッコよく見せたい人には、間違いなくこのタイプをおすすめします。

## 2つのサイズを重ねて比較してみた

せっかくなので、最初に買った「小さいサイズ」と、買い直した「ぴったりサイズ」を重ねて比較してみました。

![2つのフィルムを重ねた比較画像](/images/trex2-film-compare.jpg)

パッと見ではほぼ同じサイズに見えるんですが、よく見ると微妙に違うんです。この**「数ミリの差」が、貼り付けた時の端の歪みや干渉に大きく影響してくる**んですね。

## 【T-Rex 2】保護フィルムの貼り方と付属品

ちなみに、サイズは違えど、どちらのフィルムも貼り方は一緒でとっても簡単です。付属の道具もバッチリ揃っています。

![付属品一式](/images/trex2-film-tools.jpg)

付属の道具を使って、以下の手順で貼れば綺麗に仕上がります。

1. 付属の**湿ったシート**で画面の汚れを落とします。
2. 付属の**乾いたシート**で拭いて水分を取ります。
3. 付属の**シールのようなもの**で、画面についている埃をペタペタと取り除きます。
4. フィルムに付属の**吸盤**を貼り付け、保護シートをはがします。
5. 吸盤を持って時計の上に置くと、**勝手にピタッと張り付いていきます。**
6. 気泡が入った場合は、**中心から外に向けて**気泡を逃がすように撫でていけば綺麗になります。

※1点だけ注意。手順5で画面に置くときに、**画面の位置がズレないように気をつけてください。**

## 【T-Rex 2】バンパーカバーを付けるなら小さいサイズがおすすめ

ここまで「ぴったりサイズ」が最高だとお伝えしてきましたが、1つだけ例外があります。それは、**「バンパーカバー」を装着する場合**です。

バンパーカバーは時計のフチを覆うように付くため、画面いっぱいのフィルムだと**バンパーと干渉して端が浮いてきたり、違和感が出てしまう**ことがあるんです。

実は私も現在はバンパーカバーを付けているので、最初に買って「失敗した」と思っていた**小さいサイズのフィルムが、バンパーと絶妙に干渉せずピッタリ収まってくれる**んです。（最初は失敗だと思ったものが、まさかのリターンしてくれました）

## まとめ：あなたのスタイルに合うフィルムを選ぼう

保護フィルム選びで失敗しないためには、ご自身のスタイルに合わせて選ぶのが一番です。

* **バンパーカバーを付けないなら**：端まで守れる「画面いっぱいタイプ」がおすすめ
* **バンパーカバーを付けるなら**：干渉しない「少し小さいタイプ」がおすすめ

「買ってみないと分からない」という不安を、この記事で解消できていたら嬉しいです！

ハードな現場で3年間、Amazfit（アマズフィット） T-Rex 2を愛用しています。

最近は後継機の「T-Rex 3」も登場し、そろそろ買い替え時かな……なんて考えつつも、手元のT-Rex 2がまったく壊れる気配を見せません。

今回は、プロトレックから乗り換えて3年。実際に使ってみて感じた「良いところ」と「ちょっと気になるところ」を、正直な感想としてまとめてみました。

## 【T-Rex 2】バッテリー：3年経っても劣化を感じない安心感

3年も使えばバッテリーはヘタってくるもの……と思っていましたが、T-Rex 2は今でも十分すぎるほど持ちます。

私の使い方は、かなりバッテリーを消費する設定です。
- 画面は常に点灯（AOD）
- 画面の明るさは最大
- 心拍数の計測間隔は最短

これだけハードに使っていても、夕方にお風呂に入るタイミングで外して充電すると、残量はだいたい**70%台**。夜9時に着けるまでには100%に戻っているので、バッテリー切れで困ったことはありません。

購入当初と比べても、毎日充電しているからか、目立った劣化は感じません。この持ちの良さは、3年経った今でも素直にすごいと思います。

## 【T-Rex 2】画面：屋外での見え方と、AODによる「焼き付き」

画面の見やすさについて、**曇りの日ははっきりと綺麗に見えます**。晴れた日は少し見にくいと感じますが、使用に問題があるほどではありません。**直射日光の下ではほぼ見えません**が、時刻を見ようとすれば自然と腕の角度を変える（自分の影を作る）ので、そうすれば時刻の確認はできます。

また、3年間ずっと画面を点灯（AOD）させているため、**画面に「焼き付き（ゴースト）」は発生しています**。
普段の文字盤ではほとんど気になりませんが、再起動時の真っ白な画面を見ると、時刻の表示がうっすら残っているのが分かります。有機ELの宿命ですね。

なお、購入当初から保護フィルムを貼っていますが、タッチ操作の感度は3年間ほとんど変わらず快適です。

## 【T-Rex 2】GPSと心拍センサー：実用性は十分

GPSの精度は、購入当初と変わったようには感じません。後からルートを確認しても、だいたい通った道が表示されているので、私の使い方では不便はありません。

心拍センサーも、3年間しっかり計測してくれています。ただ、医療機器ではないので「数値がどこまで正確か」という点はそこまで気にせず、1日の変化を眺める程度の感覚で使っています。

## 【T-Rex 2】耐久性：プロトレックとの比較

私の仕事は、時計をこすったりぶつけたりすることが日常茶飯事の、かなりハードな環境です。最近ベゼルに傷が入ったので、バンパーカバーを付けて保護しています。

以前はずっとCASIOのプロトレックを使っていましたが、3年ほどで傷だらけになり、最後はガラスが曇って買い替えていました。
それに比べると、T-Rex 2は**傷もプロトレックよりマシで、耐久性は高い方**だと感じます。ディスプレイなのでガラスが曇る心配もありません。

## 【T-Rex 2】バンド：純正品の柔らかさが一番

付属の純正シリコンバンドは、1年ほどでこすれてきて、見た目が汚くなってきたため交換しました。
純正品が手に入らず、数百円のサードパーティ製バンドを半年おきに交換して使っていますが、やはり**最初に付いていた純正品が一番柔らかく、付け心地が良かった**です。純正バンドが手軽に買えないのが、少し残念なポイントです。

## 【T-Rex 2】ボタン操作：アップデートで便利になった機能

4つの物理ボタン（UP / DOWN / SEL / BACK）は、3年間変わらずカチッと気持ちよく押せます。
短押し4つ、長押し3つ（SEL/UP/DOWN）のショートカットを自由に割り当てられるので、とても便利です。（BACKボタンの長押しは固定です）

この長押しショートカットは、後からアプリのアップデートで追加された機能なんです。買った後も便利になっていくのは嬉しいですね。
ちなみに、心拍や睡眠からAIが提案する機能も追加されましたが、こちらは有料サブスクのため契約していません。

## 総合評価：コスパ最強。それでもT-Rex 3に買い替えたい理由

3年間使ってみて、**「買ってよかった、コスパ最強」**と心から思います。「壊れるまで使う」というより、「そもそも壊れるのか？」と思うほどタフな時計です。

ただ、そろそろ**T-Rex 3に買い替えたい**と考えています。理由は、やはり「傷が増えてきたこと」と、「新しいモデルの機能を試してみたいこと」です。
買い替えたい気持ちはありますが、これだけタフだと「まあいっか」となってしまいます。
