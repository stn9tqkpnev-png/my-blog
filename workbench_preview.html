Amazfit T-Rex 2 から SESAME 5 をGAS経由で解錠・施錠する

スマートウォッチ（Amazfit T-Rex 2）から、自宅のスマートロック（SESAME 5）を直接操作できたら便利だと思いませんか？

今回は、Google Apps Script (GAS) を中継地点として利用し、ウォッチから手軽に自宅の鍵を解錠・施錠する仕組みを作ったのでその手順をご紹介します。

全体の仕組み

  1. Amazfit T-Rex 2 から何らかのトリガー（通知やWebhooks等）を発信。
  2. Google Apps Script (GAS) の Webアプリのエンドポイントにリクエストを送信。
  3. GAS がセサミ（CANDY HOUSE）の公式APIを叩いて、SESAME 5を操作。

1. Google Apps Script (GAS) の準備

まずは中継地点となるGASのコードを作成します。

function doPost(e) {
  const secretKey = "YOUR_SECRET_KEY";
  const data = JSON.parse(e.postData.contents);
  
  if (data.key !== secretKey) {
    return ContentService.createTextOutput(JSON.stringify({status: "Unauthorized"}));
  }

  const sesameApiKey = "YOUR_SESAME_API_KEY";
  const deviceUuid = "YOUR_SESAME_UUID";
  const command = data.command;
  
  const url = `https://app.candyhouse.co/api/v1/sesame/${deviceUuid}/cmd`;
  const options = {
    method: "post",
    contentType: "application/json",
    headers: { "x-api-key": sesameApiKey },
    payload: JSON.stringify({ command: command, history: "Amazfit from GAS" })
  };

  try {
    const response = UrlFetchApp.fetch(url, options);
    return ContentService.createTextOutput(response.getContentText());
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({status: "Error", message: error.toString()}));
  }
}

2. 使い方とまとめ

デプロイして発行されたWebアプリのURLに対して、JSON形式で command: "unlock" などをPOST送信することで、手元から自由に鍵を動かせるようになります。
